# Color System

Colors are generated from a single HCT seed using `@material/material-color-utilities` across all **light / dark** modes, **standard / medium / high** contrast curves, and 6 scheme variants (`tonal-spot`, `vibrant`, `expressive`, `neutral`, `monochrome`, `fidelity`).

## Usage Rules

- Always pair every `X` container color with its matching `on-X` foreground token.
- Components consume `--aura-sys-color-*` or `--aura-comp-*` tokens — never `--aura-ref-palette-*` or raw hex literals.
- `success`, `warning`, and `info` are harmonized toward the active seed via `Blend.harmonize`.
